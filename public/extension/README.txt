====================================================================
Kyotei Analyzer Pro 5 - テレボート公式PC版 自動投票拡張機能 (Chrome / Edge)
====================================================================

【概要】
本拡張機能は、Kyotei Analyzer Pro 5 で算出した買い目・資金配分を、
テレボート公式PC版（https://ib.mbrace.or.jp/）へ直接連携し、
全自動投入・ファイル投票・全自動購入・公式受付番号同期を行う専用ブラウザ拡張機能です。

【インストール方法（たったの3ステップ）】

1. このZIPファイルをパソコンの任意のフォルダ（例: デスクトップなど）に解凍（展開）します。
   ※ フォルダ名例: kyotei-teleboat-pc-extension

2. Google Chrome（または Microsoft Edge / Brave）を開き、アドレスバーに以下を入力して移動します:
   chrome://extensions
   （Edgeの場合は edge://extensions）

3. 画面右上にある「デベロッパーモード」のスイッチを【ON】にします。

4. 画面左上に出現する「パッケージ化されていない拡張機能を読み込む」ボタンをクリックし、
   手順1で解凍したフォルダを選択します。

以上でインストール完了です！

【使い方】
・Kyotei Analyzer Pro 5 上で「投票」または「テレボート実投票マネージャー」を開きます。
・「PC版 拡張機能で自動投票」ボタンを押すと、自動的にテレボート公式PC版が開き、
  画面右下に【Kyotei PC 自動投票 HUD】が表示され、買い目が即座に自動投入されます。
・購入が完了すると公式受付番号が自動でKyotei Analyzerへ返信され、購入限度額から正確に減算されます。
